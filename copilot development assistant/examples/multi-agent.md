# Multi-Agent Pattern Example

## Objective

Demonstrate coordinated feature development workflow.

## Prompt

Use the Multi-Agent pattern.

Build an Order Management API.

Requirements:

* Create Order
* Get Order
* Update Order
* Cancel Order

Simulate the following agents:

1. Business Analyst
2. Solution Architect
3. Backend Developer
4. QA Engineer
5. Reviewer

Provide output from each agent separately.

## Expected Outcome

# Business Analyst

Requirements and user stories

# Architect

Architecture design and database design

# Developer

Spring Boot implementation

# QA Engineer

Test scenarios and test cases

# Reviewer

Code review and recommendations

## Pattern Characteristics

* Coordination
* Multiple responsibilities
* End-to-end delivery workflow
