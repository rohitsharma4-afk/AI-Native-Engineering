# Deliberative Agent Example

## Objective

Demonstrate planning before implementation.

## Prompt

Use the Deliberative Agent pattern.

Design a Notification Service supporting:

* Email
* SMS
* WhatsApp

Before generating code:

1. Analyze requirements
2. Identify assumptions
3. Design architecture
4. Select design patterns
5. Design APIs
6. Design database schema
7. Explain tradeoffs
8. Generate implementation plan
9. Generate code

## Expected Outcome

### Requirements Analysis

### Architecture Design

### Design Pattern Selection

### Database Design

### API Design

### Implementation Plan

### Code

## Pattern Characteristics

* Think first
* Design before coding
* Explain reasoning
